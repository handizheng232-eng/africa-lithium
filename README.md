## 详情页统一架构

每个矿山分页面均参照 Wodgina 页面，统一为：

1. 已有产线运行状况（最新披露期 vs 上一可比期）
2. 在建 / 规划中产线运行状况（严格区分可研、FID、开工、投产）
3. 整体运行状况与超预期要点
4. 历史数据（按真实披露频率，不制造季度数据）
5. 2027 年产量三情景预测
6. 选矿产能多来源核实
7. 原矿产能、资源 / 储量与卫星定位核实
8. 配套冶炼 / 转化项目（硫酸锂 / 锂盐）解析与跟踪，包含：
   - 概览卡（产能、产品、时间、投资、FID、是否计入供应、最近核验、下一观察点）
   - **设计参数**：实施主体、厂址、工艺路线、原料与入选品位、公用工程
   - **建设与进展时间线**：逐条里程碑（日期 + 事件 + 可点击来源），区分环评、开工、点火、试产、首批发运、工业投产
   - **环评与环境 / 社会影响**：EIA 证书状态、水资源与尾矿、监管处罚、社区请愿
   - **经济性 / 投资与物流**：投资额、单吨投资强度、运行负荷、出口收入、换算口径
   - **官方施工与现场影像**：企业官网原图 + 图注 + 来源日期与链接
   - **公开信源与社交媒体线索**：X / Facebook / LinkedIn / 协会与议会听证
   - **津巴布韦本项目横向对照**：该国六座矿山的硫酸锂设计产能、投资、状态与目标投产对照表，附硫酸锂→LCE 三套换算口径与本地增值政策时间线（仅津巴布韦各页显示）

### 硫酸锂口径纪律

- **硫酸锂 ≠ LCE**：1 吨 Li₂SO₄ 按公司工艺口径约合 0.50 吨 LCE（每 1 吨碳酸锂耗约 2 吨硫酸锂），按无水化学计量约 0.672 吨，按一水合物约 0.577 吨。三套并列，不合并为单一点值。
- 硫酸锂为中间品，**不得与精矿产量重复计入供应**。
- 环评、开工、点火、试产、首批发运、工业投产与达产逐级区分，不以仪式替代商业化达产。
- 公司公告口径与当地媒体报道口径不一致时（如 Bikita 10 万吨 / 2.88 亿美元 vs 媒体 12.5 万吨 / 5 亿美元），两套并列呈现并标注差异，不择优覆盖。

影像与图注：`assets/img/smelting/` 存放第⑧节引用的官方施工/现场影像；`assets/img/smelting/_captions.json` 由 `data/mines_v2.json` 自动生成（单一事实源，勿手工编辑）。

共享数据与渲染文件：

- `data/mines_v2.json`：11 页结构化研究数据与来源；
- `mine-page.js` / `mine-page.css`：统一渲染与视觉模板；
- `build_mine_pages.py`：生成 11 个详情页入口壳。

更新数据后运行：

```bash
python build_mine_pages.py
python -m http.server 8765
```

再访问 `http://localhost:8765/overview.html`；不要用 `file://`，否则 JSON 和地图 iframe 会被浏览器拦截。

## 数据口径

- **年度口径**：非洲矿山披露粒度多为年度/半年度（仅 Bougouni 为季度 RNS），故总览为年度表。
- **不做 SC6 等效折算**：产品口径不统一（SC6 / SC5.5 / 透锂长石 / 混合精矿），强行折算会失真；
  以披露口径原文呈现并逐项标注。
- **预测年取 2028E**：多数项目 2027 年才投产，2028 才是可比满产年。
- 产量/产能为 100% 资产口径；经济权益按公司持股比例折算。
- 标记「待核实」的项目不建议用于供给测算。
